# Markenbild

Mit dem integrierten Bildgenerator erstellt. Motiv: Aufgabenliste mit zwei Häkchen und Besen; Dunkelblau, Türkis und Grün, passend zur Spülmaschinen-App. Anschließend in die vorgegebenen PNG-Größen 256 × 256 und 512 × 512 exportiert.

Prompt: Modern household task manager icon, clipboard checklist with two bold checkmarks and a small broom. Deep navy outlines, teal-blue, white paper and green checks. Clean readable geometry, no text, no Home Assistant branding.
